0.81 (Multitasking Update) :
- GFRX a reçu une grande mise à jour : désormais il est possible d'avoir des couleurs en hexadécimal et les changer. De plus, on peut "démarquer" des cellules sales (utile notamment pour neofetch)
/!\ Si vous souhaitez utiliser l'ancien système de couleur, il faut ajouter l'option "oldColorSystem" lors de la création du GFRX.
- le multitasking est enfin disponible : les applications avec le tag "-- @fullscreen" se démarrent dans une nouvelle fenêtre tandis que celles avec le tag "-- @background" s'exécutent en fond, faites des tests avec la commande "task"
- la statusBar sert (avec la souris) de gestionnaire des tâches : clic gauche = sélectionne une tâche à mettre en focus ; clic droit = pause/dépause une tâche ; clic molette = tue une tâche
- lors du premier démarrage sur CraftOS-PC avec emuSpeaker, le son de démarrage se lance
- les bugs de téléchargement infini du fichier de loc dans les applications ont été réglés
- une nouvelle application de musique en fond a été créée (bgmusic.lua <path>)
- manuel.lua ne bug plus quand on entre un manuel qui n'existe pas
- textViewer.lua affiche désormais les sauts de ligne
