# FrOS
> A french ComputerCraft project.

Pour installer cet OS, il vous faudra environ 200 Ko de libre et exécuter la commande `wget run https://github.com/Timoh5709/FrOS/raw/refs/heads/main/install.lua`. Vous pourrez ensuite explorer un système d'exploitation développé principalement pour les francophones, mais aussi utilisable en anglais, basé sur la [thèse de JackMacWindows sur les OS de ComputerCraft](https://gist.github.com/MCJack123/4b2bca21bdc0cf5c67ce7177326c2154).
## Un shell intuitif :
Étant parti sur l'aspect fonctionnel, il s'agit d'un OS basé en lignes de commandes (les applications CraftOS et FrOS sont disponibles avec `exec` parce que, contrairement à CraftOS, toutes les commandes sont codées en clair dans le shell) :

## Des applications essentielles :
Plusieurs applications essentielles sont installées/installables. Parmi les applications installées par défaut, il y a `appStore.lua` et `manuel.lua`, l'une permet d'installer d'autres applications, l'autre permet aux utilisateur.rice.s ou aux développeur.euse.s de trouver facilement la documentation sur les API.

Aux prémices du projet, nous n'étions qu'un simple shell, désormais, nous pouvons archiver, traduire, utiliser l'utf8, utiliser le protocole http, faire de la 2d, faire des scripts, etc. Demain nous pourrions même aller jusqu'au shell entièrement graphique ? Qui sait !
